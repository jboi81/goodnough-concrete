# Project 1 — Goodnough Concrete LLC (real business)

A complete, responsive one-page site for **Goodnough Concrete LLC**, a real
local concrete contractor owned by Drew Goodnough (Jesse's brother-in-law).
Drew's only web presence is Facebook + TikTok — this site is his first real
website, which makes it a strong portfolio piece: a real client, a real need.

Built with plain HTML, CSS, and JavaScript — no framework — so every line is
yours to explain in an interview.

**LIVE:** https://goodnough-concrete.netlify.app — deployed 2026-10-21 on
Jesse's Netlify account (project name: goodnough-concrete). Redeploy by
zipping this folder and dropping it on the project's Deploys page.

## What's in it

- `index.html` — Hero, Services, Why Us, Reviews, Pricing, Estimate form, Footer
- `styles.css` — Mobile-first responsive layout, sticky header, card grid;
  Meta-blue (#1877F2) + deep navy palette (Jesse's pick, 2026-10-21)
- `script.js` — Mobile nav toggle, smooth scrolling, form validation
